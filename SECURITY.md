# Security policy

Please report suspected security or privacy vulnerabilities using GitHub private vulnerability reporting if enabled (Security → Report a vulnerability). If that option is unavailable, use the contact channel at https://brightery.com to request a private reporting method before sharing sensitive details. Do not post clipboard contents, passwords, tokens or exploit details in public issues.

The app stores clipboard history locally, without app-level encryption. Password-manager detection is best-effort. Use pause recording for sensitive operations and FileVault for disk protection. See the README for data retention limitations.

Security fixes are intended for the latest released version; no guaranteed response timeline or support SLA is offered.
